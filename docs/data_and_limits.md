# Data and limitations

All observations are generated by software. Electromagnetic records contain matrices in fF, adaptive-pass results, convergence status, and geometry parameters. Frequencies and Purcell lifetimes are analytic predictions from simulated matrices. No fabricated-device measurement traces were found in the reviewed release inputs.

## Protocols

1. Historical classical comparison: five numerical algorithms and Qwen, two families, five repeats, nine attempts, 0.5% extraction target and six adaptive passes maximum. The current strict convergence gate was not reapplied. Qualified double-pad counts are VLM 5, coordinate 5, Nelder-Mead 5, Bayesian 4, CMA-ES 4, Sobol 1. Historical interdigitated finals are circuit-infeasible.
2. Current cross-model searches: qualified common starts, two families, three configurations, five repeats, three rounds of three slots; 0.1% target, thirty passes maximum, explicit convergence in all required scenes. Nominal windows are 70–105 fF and 4.5–5.5 GHz. Failures and duplicates consume slots.
3. Matched structures: four references near 91–92 fF. Standard and stricter targets are distinguished. The stricter interdigitated positive-etch scene failed convergence and is excluded.
4. Held-out E2: synchronous uniform offsets ±0.25 um; left-only/right-only 0.25 um contraction with nominal ground opening fixed. Each uses its own unetched reference.
5. Readout pilot: nominal only, common 7 GHz readout, 50 ohm, loaded Q=10000, no additional Purcell filter. Predicted lifetimes are approximately 300/305/478 us for edited ring/double-pad/interdigitated. Loaded nominal frequencies fall below the required window; joint qualification is pending.

Structural calculations use EJ/h=13.28 GHz and EC/h=19.36/Csum GHz. Current model searches use the archived physical constants. Offline replay preserves this distinction.

## Annular origin

The generator seed has outer/inner radius and gap 250/115/28 um. An archived model search changes the inner radius to 122 um. A separate CMA-ES sizing run supplies 253.9/121.5/33.8 um; the selected inner-edge edit also comes from CMA-ES. These are distinct search paths. The first model reply giving the initial ring dimensions has not been recovered.

Unedited calibrated drift is 0.002584; edited drift is 0.002507. The additional 3.0%/1.6% gain under the two targets remains unresolved by numerical precision. The main structural gain does not require claiming that local improvement.

## Boundaries

Offline replay verifies recorded numerical outcomes; native projects preserve geometry and setup, without full proprietary mesh caches. New field solves can differ numerically and must be evaluated for convergence. API repeats are independent requests with no controlled service seed. Inference settings differ; configuration gains do not establish a model scaling law. Strict image attribution and current-protocol classical reruns remain future work. No fabrication yield, measured T1, or total coherence time is established.
